# VALORAE Carteira Java/XML — v1.11.0 GRÁFICOS E CONTRATOS

Versão focada em compatibilidade com o VALORAE Proxy v21.12.58, especialmente gráficos, contratos de app e contratos de classe de ativo.

## Destaques

- Consulta automática ao Proxy na abertura do app.
- Modal de ativo enriquecido com dados fundamentalistas.
- Gráfico de linha usando séries entregues pelo Proxy.
- Donut chart para faturamento por região e por negócio.
- Leitura de `appMobileSnapshot`, `appPayload`, `chartSeries`, `appRenderContract` e `assetClassContract`.
- Endpoints especializados de Ação/FII adicionados.
- Backup, restauração e importação Excel B3 preservados.
- Zero Rankings no APK.

## Build

Abrir no Android Studio/Google AI Studio e executar o build Gradle normalmente. Este pacote não inclui APK final gerado no ambiente da conversa.
